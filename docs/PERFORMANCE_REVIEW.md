# Performance review — measurement-first optimization lane

Baseline bfeed54. Inspected companion C++ mirror, benchmark, collector and ops/perf-check.sh. Not full upstream source or live profiler. No proven speedup. Contributor audit reports 62 logged-in bots, 0 active instances, p99 25ms, 0.98 GiB available of 7.17 GiB, 2.98 GiB swap occupied; occupancy alone is not swapping/thrashing. Measure actual AI active vs online and simultaneous instance mix.

## First fix the measuring instrument
[benchmark.py](https://github.com/Garblesnarff/hearthcore/blob/bfeed54e30cd39fba1bac9e1fc17dc168d41db06/hearthcore/benchmark.py#L57-L165) defaults to 3 samples of dashboard latest tick, derives p50/p95 from latest sampled ticks and max of sampled p99 windows. Labels total_online active bots and hardcodes managed_groups=0. This cannot establish true latency distribution, active workload or native correctness. Capture raw tick histograms/counters or documented nonoverlapping windows, warmup and repeated 10–30 minute comparable runs; separate humans, logged-in, active AI, idle, group/instance/map counts. Record world/DB PSS/RSS, MemAvailable, major faults, /proc/vmstat pswpin/pswpout deltas, PSI cpu/memory/io, cgroup throttling, SQL latency/queue, path calculations and decision rates. CPU profiles (perf stat/record, symbols, short approved staging windows) and coarse sampled subsystem timers, not per-tick log. Capture exact build/config/image/workload, repeated before/after same fixtures. No destructive live load, no production data in public repo. Tie resource admission (#12) to measured fresh actual data.

## Execution
Perf-00 baseline and actual profiles; Perf-01 fix benchmark and admission telemetry; Perf-02 top measured hotspot, one small isolated PR; Perf-03 compare native dungeon run at same total population, then more groups only with measured headroom. Test owner-led Stockades/Gnomeregan baseline and bot-only RDF separately. Require actual correctness assertions (pull/heal/route/loot/outcome), compare repeated p95/p99, CPU, PSS, swap I/O, progression/stalls and rollback. Provisional target from Phase II <= baseline + max(2ms,5%) comparable p95/p99 and no new sustained swapping; ratify against actual distribution. Do not promise new bot capacity before profiling. Prefer meaningful active players over logged-in count; no automatic host or config changes. Keep gear catalog offline/shared and no per-bot full DB queries or extra LLM requests.
